# Documentation Structure

This directory contains all project documentation, organized by type:

## 📂 Folders

### [wiki/](./wiki/)
Permanent documentation, including architecture, database schemas, guides, and technical standards.
- `SYSTEM_ARCHITECTURE.md`: Overview of the system design.
- `DATABASE_SCHEMA.md`: Full reference for the database schema, types, and SQL.
- `QUICKSTART.md`: Guide for new developers.

### [update/](./update/)
General project updates, monthly summaries, and significant milestone logs.

### [update-feature/](./update-feature/)
Detailed documentation for specific feature implementations and updates.
- `UPDATE_<DATE>_<FEATURE_NAME>.md`

### [hot-fix/](./hot-fix/)
Documentation for critical bug fixes and hotfix reports.

---
*Follow this structure when adding new documentation files.*
