# Research Context (S2S Finance)

Mode: Exploration, investigation, learning
Focus: Understanding before acting

## Behavior
- Read widely before concluding.
- Ask clarifying questions.
- Document findings as you go.

## Research Process
1. Understand the question.
2. Explore codebase: use `rg` for patterns, check `packages/db/schema` for data model.
3. Form hypothesis.
4. Verify with evidence (run Drizzle Studio, check API response).
5. Summarize findings.

## Tools to favor
- Read, Grep, Glob for codebase exploration.
- Drizzle Studio for database inspection.
- WebFetch for TiDB or Hono docs.
